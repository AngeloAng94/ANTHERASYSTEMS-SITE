# Product logos

Drop each product's SVG logo in this folder, with these **exact** filenames:

| File | Product |
| --- | --- |
| `powerleave.svg` | PowerLeave |
| `govern-ai.svg` | GOVERN.AI |
| `antheralearn.svg` | AntheraLearn |
| `agent-aier.svg` | agentAIer |

The site loads them automatically from `/products/<file>.svg`
(rendered by `ProductLogo`).

Until a file is added, that product keeps its previous logo/icon as fallback,
so you can upload them one at a time.
